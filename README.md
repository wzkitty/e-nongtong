## 🌾 e农通智慧农业平台（e-NongTong）
>结合教育培训与电商销售功能的综合性平台，秉持袁隆平所言“农业的未来在于科技”的理念，将新职业农民培训与农机购买一体化。该平台主要服务于新型职业农民，通过提供一系列的课程培训和资源输出，包括课程免费学习与农需农机购买途径的双重支持，旨在为愿意接受新技能知识的农民提供农机培训购买的一体化帮助，帮助新农人掌握和提升使用现代化高科技农业机械设备的技能，搭建一个可以持续学习新技术的云端平台，以提高新质生产力的生产效率

---

## 📌 一、项目背景

在乡村振兴与农业现代化背景下，传统农业面临技术获取难、信息渠道有限等问题。  
“e农通”平台旨在通过数字化手段，整合农业知识资源与技术服务，构建一个集**学习、传播与应用**于一体的智慧农业平台。

---

## 🎯 二、项目目标

- 提供系统化农业技术学习资源  
- 推动农机使用与现代农业知识普及  
- 构建轻量化在线教育平台原型  
- 探索“互联网 + 农业”的应用模式

## 🚀 四、核心功能

## 🎬 七、视频实现方案

本项目采用 **Bilibili嵌入播放器** 实现在线视频播放：

<iframe src="//player.bilibili.com/player.html?bvid=BV号&page=1"></iframe>
✔ 优势：
无需服务器存储视频
视频资源丰富、稳定
降低系统开发复杂度
提升用户观看体验
